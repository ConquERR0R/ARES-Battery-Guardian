
# ARES Battery Guardian — Privacy Policy

**Last updated:** November 22, 2026

## 1. Introduction

ARES Battery Guardian is a Windows desktop application designed to monitor laptop battery information and provide battery protection alerts.

We respect user privacy. This policy explains what information the application handles and how it is stored.

## 2. Information handled by the application

ARES may process the following information locally:

- Battery percentage and charging status.
- Battery health, capacity, voltage, and other available battery readings.
- Battery history and charging/discharging sessions.
- Application settings and protection thresholds.
- Application events and diagnostic logs.
- Basic hardware and Windows information used for compatibility diagnostics.

## 3. Local data storage

ARES stores its application data on the user's computer.

On Windows, the default location is:

`%LOCALAPPDATA%\ARES Battery Guardian\`

This includes its local SQLite database, battery history, settings, and logs.

## 4. Data transmission and third-party services

The current published version is designed to process and store battery information locally.

ARES does not provide user accounts, cloud synchronization, advertising, or built-in analytics services.

Users may independently choose to share exported reports or diagnostic information. Such sharing is initiated by the user.

Downloading updates or installers from GitHub involves GitHub's own services and privacy practices.

## 5. User control

Users can manage their application settings and locally stored information.

Users should keep their own backups of important battery history and exported reports.

## 6. Children's privacy

ARES Battery Guardian is a general-purpose desktop utility and is not specifically designed to collect personal information from children.

## 7. Changes to this policy

This policy may be updated when application features or data practices change. Updated versions will be published in the official GitHub repository.
