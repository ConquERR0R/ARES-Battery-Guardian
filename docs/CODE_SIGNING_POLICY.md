
# ARES Battery Guardian — Code Signing Policy

## Signing status

ARES Battery Guardian is applying for free open-source code signing through the SignPath Foundation.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

The application has not yet been approved by SignPath Foundation. Until approval and signing are completed, published Windows installers remain unsigned.

## What will be signed

The intended signing scope is the Windows installer:

- ARES-Battery-Guardian-V2-Beta-Setup.exe

Only binaries built from the ARES Battery Guardian source code in the official repository will be submitted for signing.

## Team roles

- **Committer and maintainer:** ConquERR0R
- **Reviewer:** ConquERR0R — reviews contributions from external contributors before merging.
- **Approver:** ConquERR0R — manually reviews and approves each signing request.

## Release approval

Each release signing request must be manually reviewed and approved by the project approver. No release should be represented as signed until its signature has been verified.
